# soil-health-fertilizer-recommendation-system

🌱 Soil Health & Fertilizer Recommendation System

An intelligent Machine Learning + Flask web application that recommends the best fertilizer based on **soil nutrients, crop type, growth stage, weather conditions, and real-time climate data.

It also provides:

🌾 Soil health analysis
🌦 Real-time weather insights
💰 Estimated fertilizer cost
🤖 Explainable AI reasoning

🧠 Features

🌱 Smart Fertilizer Prediction
* Predicts best fertilizer using ML model (Random Forest)
* Uses soil NPK values + pH + crop type + growth stage

🌦 Weather Integration
* Real-time weather data using OpenWeatherMap API
* Temperature, humidity, rainfall analysis

🧪 Soil Health Analysis
 Classifies soil as:
  * Good
  * Moderate
  * Poor

💰 Cost Estimation
 * Shows estimated fertilizer cost

🤖 Explainable AI
* Provides human-readable reasoning for recommendation

📍 Multi-city Support
* Works for multiple cities across India

* Input Features:

  * Nitrogen
  * Phosphorus
  * Potassium
  * Temperature
  * Humidity
  * Rainfall
  * Crop Type
  * Growth Stage

* Output:
  * Recommended Fertilizer
